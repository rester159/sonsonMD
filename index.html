SonSon MD

An unofficial, native Genesis port of Capcom's 1984 arcade game SonSon. It was rewritten from scratch in C with SGDK rather than emulated or translated, so it runs at the console's full 60 fps.

1–2 players, simultaneous co-op Arcade & Home modes Instadeath survival Battery saves Source only

Modes

Arcade

Coin up with C, then Start on either controller to join or rejoin. Arcade coinage DIP switches are respected, including free play.

Home

Choose 1 or 2 players from the title menu. Start pauses, A/B/C fire, and a shared pool of 0, 3, 5 or 9 continues is set in Options.

Instadeath survival

One life each; any contact kills. Pressure rises every 20 seconds with more enemies, faster spawns and faster foes. Best times are kept separately for 1P and 2P.

SRAM saves

High scores, survival records, Home options and Arcade DIP switches persist in cartridge SRAM. Two CRC-protected slots guard against interrupted writes.

Frame rate

v1.0 fixes how the game handles frames that run late. The arcade logic still runs at its original 55.4 Hz; display and logic are decoupled, so the game speed is unchanged.

Build it

Requires SGDK 2.11 and an m68k-elf-gcc toolchain. The repository includes the generated game graphics and sound tables, so no arcade ROM is needed to compile.

git clone https://github.com/rester159/sonsonMD.git
cd sonsonMD
SONSON_GDK=/path/to/sgdk bash build.sh   # writes out/rom.bin

Run out/rom.bin in an accurate Genesis emulator such as Genesis Plus GX, BlastEm or MAME (mame genesis -window -cart out/rom.bin), or on hardware with a flash cart.
