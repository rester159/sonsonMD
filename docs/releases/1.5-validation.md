# Collection v1.5 — stage-one climbing performance

2026-10-28. Further CPU reductions for SonSon II's log and vine areas.
The steady log workload now reaches NTSC refresh rate, but initial approach
misses remain. This release does not establish stutter-free full gameplay.

## Changes

- Replay cached sprite rows before decoding unchanged source sprite dimensions,
  palette and cell alignment; preserve cache ageing, clipping and sprite limits.
- Traverse cached composite parts with pointers, preserving SAT wrapping and
  publishing the cursor/count/high mark once per composite.
- Use an exhaustively checked 68000 byte-join primitive in selected hot paths,
  and cheaper mapped-page addressing. Skip identity camera-axis rebasing writes.
- Convert two source pixels at a time using a small palette-dependent table.
  Preserve transparency, source wrapping and invalid-source clearing.
- Add sparse diagnostic checkpoints and external full-state capture so the
  recorder does not materially distort near-budget frames.

No actors, collision checks, simulation steps or sound events were removed.
Speculative queued map rows did not improve the early misses and were reverted.
A further spawn optimization triggered the GCC auto-increment hazard check and
was also reverted.

118 shared sparse checkpoints match camera X/Y, player X/Y, RNG and actor

Independent video at refreshes 1000–1239 has 239 changed images in all 239

the video evidence covers only this sample.

Across the early approach, three repeated prepared counts remain at host
refreshes 389, 391 and 393 (simulation ticks 184, 186 and 188). The vine fixture
starts at (532,1320), alternates up/down every 40 ticks, and retains one early
repeat at refresh 286, tick 81. Its steady section was already full-rate in
v1.4. The exact user's full vine ascent is not yet reproduced/validated.

## Reproduction

From the repository root, with the owner's local source assets:

```sh
python3 tools/build_native.py -D SS2_DBG_STAGE=0 -D SS2_DBG_WX=1408 \
  -D SS2_DBG_WY=1712 -D SS2_PERF_INPUT -D SS2_PERF_CLIMB \
  -D SS2_PERF_SPARSE --out out/log-check
python3 tools/ss2/perf/benchmark.py out/log-check out/log-check/run
python3 tools/ss2/perf/capture_completed_state.py out/log-check out/log-state
python3 tools/ss2/perf/check_cell_decoder.py
```

Use WX=532, WY=1320 and SS2_PERF_UP instead of SS2_PERF_CLIMB for the short
vine fixture. SS2_PERF_UP_PERIOD=320 extends the up/down cycle. Build with
SS2_COMPCHECK and SS2_SPRCHECK for the target renderer comparison (do not use
that slower diagnostic build as the performance measurement).

Physical hardware, PAL, complete upward traversal and full-game worst cases
remain unvalidated. This document does not assert an itch.io upload.

Release binary: 2,097,152 bytes, checksum `c2d6`.
SHA-256: `24278f5cb60ffa5f0de816b44db1aa165125ead885cd55f8692d3aed7b915968`.
Release header, checksum, diagnostic-free flags and source hashes pass

Normal release boot, intro skip and platform-colour smoke check pass in MAME.
