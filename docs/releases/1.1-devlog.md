# The SonSon Collection v1.1 — shop graphics, sound and performance fixes

Version 1.1 is a bug-fix update for The SonSon Collection. Download
**SonSonCollection-v1.1.bin** and replace the previous ROM on your flashcart or
in your emulator.

Thanks to everyone who tested the collection and reported issues, especially
jackic, ROBOT-RANDOM, marmartin3 and merman1974.

## What changed

- **SonSon II shop exits:** clear the shop's sprite table before returning to
  the stage. Shop goods and cursor pieces could otherwise remain visible in
  sprite slots reserved for the cloud and staff.
- **SonSon II volume:** raise the FM output level to address the quiet sound
  reported on Genesis Models 1 and 2. Music and effect sequencing is unchanged.
- **Startup and reset:** initialize work RAM and game state on every cartridge
  entry, including when a flashcart leaves controller registers configured.
  This addresses a verified startup failure path associated with our Model 3
  investigation; confirmation on physical Model 3 VA1 hardware is still needed.
- **SonSon II performance:** optimize terrain collision lookups and object
  movement while preserving gameplay calculations. Matched emulator workloads
  showed modest presentation-throughput gains in stages 2 and 7.
- **Vertical scrolling:** reduce new-row map-streaming time from 37 to 23
  scanlines in a repeatable stage-one climb. That is about 38% less time for
  this part of rendering, not a 38% whole-game frame-rate increase. Crossing
  the world's wrap boundary now streams the new border instead of redrawing
  the entire view.
- **ROM identification:** the cartridge title and download now identify the
  Collection as v1.1, and the ROM header declares the full 2 MiB image.

The SonSon I repeating pickup-jingle correction from the earlier Collection
build remains included. If you are still using the old standalone SonSon I
v1.0 download, please use this Collection release instead.

## Testing and remaining limitations

The release was checked in emulation, including startup/reset and the shop
transition. Native terrain and movement tests preserve the original arithmetic,
and the scrolling checks preserve the rendered tiles. Earlier audio checks
covered all 43 sound requests plus overlapping music/effects without digital
clipping in that test.

Stuttering can still occur in demanding scenes. The repeatable climbing test
shows more rendering headroom but does not reproduce every reported hitch.
Physical-console confirmation is still needed, particularly on Model 3 VA1
and older EverDrive models. Please include the ROM version and your console,
flashcart and firmware when reporting results.

English and Japanese language options remain available; this update does not
replace the English translation. The alternate-translation suggestion is noted
for a separate review.
