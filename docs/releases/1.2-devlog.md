# SonSon Collection v1.2 + standalone SonSon II

Thanks to Ray Castello for the latest feedback. This update adds the requested
standalone SonSon II ROM and improves background colour conversion and scrolling.

- **Standalone download:** SonSonII-v1.2.bin starts SonSon II directly after the
  opening logos. Start+C returns to its title. SonSonCollection-v1.2.bin keeps
  both games and the game-selection screen.
- **Background colours:** each tile can now use whichever of the two background
  palettes reproduces its colours more accurately. This reduces avoidable
  colour changes without adding runtime work. Stage-one conversion error falls
  by about 9.6% in the source-colour comparison; the Genesis palette constraints
  still mean some colours and shading differ from the PC Engine.
- **Scrolling:** new columns reuse metatile lookups, reducing map-streaming work.
  The repeatable stage-one test shows a small improvement in frame pacing.
  Demanding scenes can still stutter; this is not a complete fix for every hitch.

The v1.1 shop-exit, volume, startup and SonSon I jingle fixes remain included.
English and Japanese options are unchanged.

Validation covers the background pixels in all seven stages, scrolling boundary
cases and emulator startup/gameplay checks. Physical-console and older
EverDrive confirmation is still needed. If a problem persists, please include
which v1.2 ROM you used, your console/emulator and the location in the stage.
